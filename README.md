# La Panacha - Recipe Manager Console App

## 📌 About the Project

**La Panacha** is a console-based recipe manager application developed as part of my academic internship at **Indra Company** during the first semester of 2024.
The project focuses on learning and applying clean Java programming practices, JDBC for database interactions, and a structured backend design without using frameworks like Spring Boot.

---

## 🧩 Features

* **Recipe Management**: Create, edit, view, and delete recipes.
* **Ingredient Management**: Manage ingredients with their categories and measurement units.
* **Recipe Composition**: Assign ingredients and preparation steps to each recipe.
* **Database Integration**: MySQL database managed through XAMPP.
* **Structured Codebase**: Follows DAO-Service-UI design for clean separation of concerns.

---

## 📂 Technologies Used

* Java SE 21
* MySQL (XAMPP)
* JDBC
* MVC Pattern (DAO-Service-UI Layers)
* Git for version control

---

## 📌 Project Highlights

* Complete backend system without the use of frameworks, focusing on solid Java fundamentals.
* Structured code with modular services.
* Implements basic CRUD operations and category filtering.

---

## 🖥️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Dafesaro/La-Panacha.git
   ```
2. Import the SQL database into your local MySQL server using XAMPP.
3. Open the project in your IDE (recommended: VSCode or IntelliJ).
4. Compile and run `MainApp.java`.
